# Security policy

This project is a local, read-only metadata gate. It must not receive
credentials, private knowledge bodies, customer data, model outputs, or live
approval ledgers.

Do not open a public issue containing a secret or private asset. For a private
report, use the private contact channel supplied by the maintainer of the
handoff you received, and include a minimal reproduction without sensitive
data.

The package does not provide a network listener, external API client,
scheduler, daemon, or automatic state-changing path.
