# Release preparation

1. Run the KLG and router checks in the root README.
2. Scan the complete tree for secrets, private paths, operational identifiers,
   generated files, and live execution surfaces.
3. Build and inspect an archive in a temporary directory.
4. Confirm the MIT license and public-surface exclusions.
5. Obtain an explicit human publication decision before creating a public
   repository, tag, registry upload, or CI workflow.

This candidate contains no publication credentials or deployment automation.
