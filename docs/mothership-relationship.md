# Mothership relationship

Knowledge Lifecycle Kit is an independent Mothership wider-constellation
companion. Mothership does not discover, install, invoke, or configure it.

Knowledge Lifecycle Kit is not registered in Mothership's frozen protocol suite
and does not claim suite compatibility. Knowledge Lifecycle Gate remains
read-only; advisory routing remains non-authorizing and cannot select or start
a worker.

Any future interchange protocol requires a separately versioned schema,
identified semantic owner, public fixtures, Mothership snapshot review, and a
coordinated release. This repository does not infer that compatibility.
